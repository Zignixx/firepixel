# Firepixel: Stand

Je Crate ein Abschnitt. Der zuständige Agent pflegt Stand, Messzahlen gegen die Referenzen und offene Punkte.

## Nacharbeiten für die Integrationsphase (vom Koordinator gesammelt)
- fp-fwpng: `guess_active_page` wählt teils die falsche Seite (Befund fp-render).
- fp-model/fp-engine: Effekte an Rechteck-Primitiven zusätzlich in `PRIv/EFLv` pflegen (sonst verliert das Original den Schatten).
- fp-render: Mischmodi innerhalb von Symbolinstanzen wirken im Original wie Normal; Vorgabe `symbol_blend_modes = false`, prüfen.
- fp-vector: natürliche Pinsel 5/28 pixelgenau (Schwärze-Tinte, Zufallsfolge, transformierte Spitzen), Muster mit trigonometrischer Matrix.
- fp-text: Text auf Pfad 2/9, Alt-Rahmentexte ohne ATE (Unterkante 271/678).
- fp-io: AVIF- und HEIC-**Import** fehlen (Nutzerwunsch). AVIF über einen reinen Rust-Dekoder (z. B. rav1d/re_rav1d + avif-parse) statisch einbauen; HEIC nur, wenn ohne DLL machbar.
- fp-render/fp-engine: `fp_export::render::PageRenderer` für den echten Renderer umsetzen; offene Export-Befehle in fp-engine auf `fp_export::{doc_export, export, preview, size}` umstellen.
- fp-io: CMYK-JPEG nur 2512/4096 Pixel gleich (anderer JPEG-Dekoder); progressives JPEG nur Spektralauswahl; grafische Pop-up-Menüs (`mmmenu*`) fehlen; SVG-Verläufe vereinfacht.
- fp-color: CMYK-Tabelle nur zur Laufzeit aus einer vorhandenen Installation des Originals; Rückfall-Näherung ohne Installation prüfen.

- fp-engine (Befund fp-script/fp-mcp): `commands::file::{load_document, save_document}` öffentlich machen (Adapter `fp_mcp::tools::save_fwpng_copy`, `fp_script::imp::doc::save_copy`); Befehle für customData, Text-Rahmenart/Glättung/Kerning/Richtung, Ebenen-Aufklappen und `Document.left/top` (Leinwandursprung) fehlen – fp-script ändert diese Felder direkt im Modell (`imp::edit_doc`/`elem::edit_direct`, ohne Verlaufsschritt); `element.setBounds`/`edit.move` ohne `ids` (fp-script wählt vorübergehend aus).
