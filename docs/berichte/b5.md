## Neue Befunde

1. **(fp-engine/fp-ui, mittel)** Mit aktiver Unterebene verweisen Ebenenbefehle mit Vorgabe „aktive Ebene“ (`layer.move`, `layer.duplicate`, `layer.setShared`, „Über Status teilen“) auf die Unterebene und melden „Ebene nicht gefunden“; `layer.delete` ist angepasst. Das Ebenen-Bedienfeld hebt eine aktive Unterebene noch nicht als aktiv hervor, ein Klick auf eine Unterebenenzeile aktiviert sie nicht. Verhalten des Originals für diese Fälle ungemessen.
2. **(fp-export, mittel)** Schaltflächen-Segmente im HTML-Export ohne Rollover: Das Original erzeugt aus den Schaltflächen-Optionen (`IDSb`, re\15 §2) Verhalten (Bild austauschen/Navigationsleiste) und Bilder der Status 2–4 aus den Symbol-Status. Firepixel exportiert nur Status 1 mit Link.
3. **(fp-script, klein, Messung)** `addNewHotspot("slice")`: Segmentname in JSF (`name`) ist `null`; das Original zeigt im Inspektor den automatischen Namen „_r2_c2“ – ob `name` in JSF ihn liefert, ist ungemessen.
4. **(fp-script, klein)** `reorderLayer` einer Unterebene auf eine Ebene der obersten Stufe ist eine Annahme (oberste bzw. unterste Unterebene darin), ungemessen.
